How this connects to the real model

  1. Browser gets the real camera stream.
  2. Browser captures JPEG frames.
  3. Backend sends each frame to your ISL recognition model/API.
  4. The model returns a sign label and confidence.
  5. Text is shown and can be spoken.
  6. For reverse communication, text is converted into a sign sequence and played by the avatar.
This package does not pretend that a label list is a trained 200-sign recognizer. Connect the actual trained ISL model through MODEL_API_URL.
